# 🚀 ChurnAI - Intelligent Customer Churn Prediction System

### Predict Customer Churn with Machine Learning & Interactive Analytics

An end-to-end AI-powered web application that predicts whether a telecom customer is likely to churn using a trained Machine Learning model. The platform combines predictive analytics, interactive dashboards, secure authentication, and a premium user experience to help businesses identify at-risk customers before they leave.

# ✨ Overview

Customer churn is one of the biggest challenges in the telecom industry.

**ChurnAI** uses Machine Learning to analyze customer behaviour and predict whether a customer is likely to leave the service.

Instead of manually analysing thousands of records, users can simply enter customer information through a modern web interface and instantly receive a churn prediction along with business insights.

# 🧠 Machine Learning Pipeline

The prediction model follows a complete ML workflow:

- Data Collection
- Data Cleaning
- Feature Engineering
- Data Preprocessing
- Model Training
- Model Evaluation
- Model Serialization
- Real-time Prediction

Model used:

> Random Forest Classifier

The trained model is saved using **Joblib** and loaded dynamically inside the Flask application.
